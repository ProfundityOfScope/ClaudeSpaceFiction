# Working in this repository

Read `ROADMAP.md` before doing anything else. It holds where the project stands, what the owner has asked for, the plan, and the rules that keep saved voyages stable. Update it in the same commit as the work it describes.

Quick reference:

- `npm run check`, `npm test`, `npm run build`, `npm run bot`
- Edit `src/`, then build: `docs/index.html` is generated and is what the public page serves.
- Work on a branch, open a pull request to `main`. Do not push tags or force-push.
